Conexión al SQL Server: dónde se demora

Descargar CSV (3 días)

Cada punto es una medición. Verde: lo que tarda la red hasta el servidor (conexión TCP, sin login). Azul: lo que tarda una consulta mínima por la conexión ya abierta. Ámbar: lo que tarda abrir una conexión nueva y entrar. Rojo: sin respuesta. Si el verde está bajo y el azul o el ámbar suben, el SQL Server está ocupado o trabado; si el verde también sube, es la red o la máquina. Escala logarítmica (cada raya es 10 veces más). Se guarda una medición por minuto y todas las lentas, durante 7 días.

Cortes y demoras del SQL Server

Cada fila es un episodio: mediciones malas seguidas (separadas por menos de 90 segundos) se cuentan como uno solo. Corte: alguna medición no tuvo respuesta. Demora: respondió, pero tardó más de 1 segundo. La duración va desde la primera hasta la última medición mala; el corte real puede ser algo más largo, porque se mide cada 5 a 15 segundos. Usa el mismo período que el gráfico de arriba.
