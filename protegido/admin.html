Agregar compresor

La IP, puerto, marca y los coils Modbus solo se cargan y editan acá. El resto de los usuarios con permiso de Compresores solo ve el nombre y programa el horario, nunca estos datos. El compresor no habla Modbus directo: la IP/puerto son los del PLC que tiene cableado el relé de marcha/paro del compresor. "Coil de marcha" es la dirección que el sistema ESCRIBE para comandarlo (1 = orden de marcha, 0 = orden de parada); "coil de estado" es una dirección aparte que el sistema solo LEE, cableada al contacto de "marcha" real del compresor, para saber si está efectivamente encendido.

Backups

Se genera un backup automático de la base de datos y los PDFs cada 6 horas, en un lugar separado de los datos principales. Se conservan los últimos 28. Para máxima seguridad, descargá uno de vez en cuando y guardalo fuera del servidor.
